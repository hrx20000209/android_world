# 01 证据保留的交互图（Stage A）

## 构建
- 来源：`trace_reachability_validation/raw/full/*`，共 1262 个已执行 episode（BASE、FULL v1–v5，seed 30/31）。每一步都按真实执行的前后两个 a11y 状态重建，脚本为 `scripts/memory.py: extract`。
- **O（不可变观测）**：13046 条，存于 `graph/observations.jsonl`（18 MB）。每条记录包含：任务、模板、运行实例、episode 成败、来源（model / jump / replay）、操作 o、槽位身份、参数 θ、绑定结果、安全分类、源状态与目的状态（activity、layout、struct、目的页可见标签）。
- **V / E**：状态键 = activity + layout 签名，共 446 个；点击类边 784 条。冲突的后继全部保留。
- **快照**：留一模板。目标模板及其编号变体（去掉末尾数字后同名）都被排除；快照只是对 O 的一个视图（`Snapshot`），不改写 O。
